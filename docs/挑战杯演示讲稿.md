# 执图破局 · 挑战杯演示讲稿（约 4–5 分钟）

## 30 秒启动

1. 双击仓库根目录 `start_all.cmd`（后端 `:5000`，前端 `:8888`）
2. 浏览器打开入口 → 滚到登录（或点「立即登录」）
3. 点 **开发者入口**（本地自动登录 `developer`）→ 进入 **岗位大新闻**

若开发者入口报错：确认 `http://127.0.0.1:5000/api/health` 返回 ok。

---

## 演示剧本与话术

### 1. 入口（20s）
「执图破局把散落的招聘文本收成可核对的岗位—能力结构。」  
滚到介绍 → 立即登录 → 开发者入口。

### 2. 岗位大新闻（40s）
「评委首先看到市场叙事：本期头条、核心涨幅、五大信源。」  
点一条头条或信源卡，说明「新闻不是装饰，是发现与地图的入口语境」。

### 3. 数字人才地图（45s）
顶栏切到地图。「全国热力一屏可读；悬停省份看岗位量与薪资，点击下钻城市与技术图谱。」  
若接口慢：诚实说「正在拉库」，不要假装点完就有假数据。

### 4. 岗位洞察 / 能力演化（40s）
「同一套能力语言：时间滑块看能力图谱随版本变化。」  
拖滑块 / 点节点，强调「可解释、可回放，不是黑箱推荐」。

### 5. 新岗位发现（50s）
「真实发现 vs 未来预测分栏。」  
点 **查看发现日报** → 扫 Top 卡 → 进详情 → **对比简历** / **收藏到仓库**。  
扫描若走 Mock：琥珀色提示「后端不可用已切换 Mock」——话术：「演示环境可降级，正式库接通后同一套 UI。」

### 6. 人岗匹配（40s）
「简历与岗位用同一能力坐标系对照缺口。」  
可走上传/已有简历 → 看缺口与推荐岗；未完成步骤会 amber 拦住，按提示走。

### 7. 个人仓库（30s）
「发现页收藏直接落入仓库，简历版本也在这里。」  
展示「新岗位发现」泳道里刚收藏的岗位。

## 失败兜底话术

| 现象 | 说法 |
|------|------|
| 后端连不上 | 「本地 API 未起，我这边用 start_all 拉起后再走一遍。」 |
| 地图空白 | 「该省样本稀疏，我们看有数据的省份；空态是设计过的。」 |
| 发现 Mock | 「降级到启发式样本，链路与正式扫描同一交互。」 |
| 匹配未上传简历 | 「先从仓库取演示简历，再跑匹配。」 |
